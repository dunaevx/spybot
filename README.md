# SpyBot — игра «Шпион» в Telegram

Бот ведёт партию «Шпион» в группе: набирает игроков, раздаёт роли в личку, ведёт раунды обсуждения и голосования, считает статистику.

## Возможности

- Отдельная игра в каждой группе; управляют ведущий (кто начал набор) и админы.
- Темы слов: Места, Еда, Кыргызстан, Профессии, Животные, Предметы, Спорт, «Всё подряд» и свои слова чата.
- Шпион угадывает слово командой `/guess` в личку (одна попытка), со второго раунда получает подсказку.
- Шпионы знают напарников; роль выбывшего раскрывается; в конце — «лучший детектив».
- Статистика игроков и рейтинг чата (`/stats`, `/top`).
- Настройки чата кнопками (`/settings`): время фаз, число шпионов, раунды, подсказка, тема по умолчанию.
- Игры сохраняются в базу: если бот перезапустится, партия продолжится с прерванного раунда.

## Запуск

```bash
docker build -t spybot .
docker run -d --restart unless-stopped -e API_TOKEN=<токен от @BotFather> spybot
```

## Переменные окружения

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `API_TOKEN` | — | токен бота (обязательно) |
| `DATABASE_URL` | — | Postgres (`postgresql://...`). Если не задан — SQLite-файл `DB_PATH` |
| `DB_PATH` | `/data/spybot.db` | путь к SQLite-файлу. Чтобы данные переживали перезапуск, нужен постоянный диск (volume) |
| `REGISTRATION_SECONDS` | 180 | длительность набора по умолчанию |
| `DISCUSSION_SECONDS` | 120 | длительность обсуждения по умолчанию |
| `VOTING_SECONDS` | 60 | длительность голосования по умолчанию |
| `MIN_PLAYERS` | 3 | минимум игроков (не меньше 3) |
| `MAX_ROUNDS` | 5 | после стольких раундов побеждают шпионы |

Значения времени и раундов — только умолчания: каждый чат может поменять их через `/settings`.

## Команды

Игра: `/game [тема]`, `/ready`, `/vote`, `/end`, `/guess слово` (в личку), `/role` (в личку), `/rules`.
Чат: `/settings`, `/top`, `/stats` (можно ответом на сообщение игрока), `/words`, `/addword слово1, слово2`, `/delword слово`.
