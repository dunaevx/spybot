# SpyBot — игра «Шпион» в Telegram

Бот ведёт партию «Шпион» в группе: набирает игроков, раздаёт роли в личку, ведёт раунды обсуждения и голосования.

## Запуск

```bash
docker build -t spybot .
docker run -d --restart unless-stopped -e API_TOKEN=<токен от @BotFather> spybot
```

## Настройки (переменные окружения)

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `API_TOKEN` | — | токен бота (обязательно) |
| `REGISTRATION_SECONDS` | 180 | сколько длится набор |
| `DISCUSSION_SECONDS` | 120 | длительность обсуждения |
| `VOTING_SECONDS` | 60 | длительность голосования |
| `MIN_PLAYERS` | 3 | минимум игроков (не меньше 3) |
| `MAX_ROUNDS` | 5 | после стольких раундов побеждают шпионы |

## Команды

- `/game` — начать набор в группе
- `/ready` — начать игру досрочно (ведущий или админ)
- `/vote` — закончить обсуждение и перейти к голосованию (ведущий или админ)
- `/end` — остановить игру (ведущий или админ)
- `/guess слово` — шпион угадывает слово (в личку боту, одна попытка)
- `/role` — напомнить свою роль (в личку)
- `/rules` — правила
